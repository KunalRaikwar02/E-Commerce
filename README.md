# VELTORN - Full Stack MERN E-Commerce Platform

## Overview

VELTORN is a modern full stack e-commerce platform built using the MERN Stack. The application provides a seamless online shopping experience with secure authentication, product browsing, advanced filtering, shopping cart management, order tracking, Razorpay payment integration, AI-powered assistance, and a complete admin dashboard.

The project follows a modular and scalable architecture, making it suitable for real-world e-commerce applications.
